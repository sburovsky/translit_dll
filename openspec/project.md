# Project Context — translit_addin

## Назначение

Внешняя компонента 1С:Предприятие (Native API), написанная на Rust, для
транслитерации русского текста (кириллица → латиница). Собирается в DLL для
Windows x86 (i686) и x64 и упаковывается в `translit.zip` для загрузки в общий
макет 1С типа «Двоичные данные».

Проект реализован и протестирован. Данный каталог OpenSpec документирует
существующее (сложившееся) поведение системы в виде спецификаций и задаёт
правила ведения изменений в дальнейшем.

## Технологический стек

| Компонент | Версия / деталь |
|---|---|
| Rust | stable, edition **2024** (в `Cargo.toml`) |
| Тип библиотеки | `cdylib` + `rlib` (`rlib` нужен для `cargo test`) |
| `native_api_1c` | 0.10.7 — обёртка Native API 1С |
| `translit` | 0.8.0 — таблицы транслитерации (MIT) |
| `utf16_lit` | 2.0.2 — строковые литералы UTF-16 |
| cargo-make | 0.37+ — оркестрация сборки (`Makefile.toml`) |
| Платформа 1С | 8.3, Native API (внешняя компонента) |
| Toolchain / targets | `x86_64-pc-windows-msvc`, `i686-pc-windows-msvc` |

## Структура проекта

```
translit_dll/
├── src/lib.rs        # компонента TranslitAddin + логика транслитерации + тесты
├── Cargo.toml        # зависимости, crate-type = ["cdylib", "rlib"]
├── Makefile.toml     # cargo-make: clean → release → remove-out → pack-to-zip
├── Manifest.xml      # манифест компоненты (x86 / x64)
├── out/              # артефакты: translit_x32.dll, translit_x64.dll, translit.zip
├── .clinerules/      # правила проекта (00-general, 10..14-1c, 20-rust)
└── openspec/         # этот каталог спецификаций
```

## Соглашения

- Имена в 1С-коде и doc-комментарии в Rust — на русском языке.
- Логика отделена от FFI: чистые публичные функции (`transliterate(...)`,
  `TranslitSystem::from_code(...)`) тестируются без подключения компоненты.
- В рабочем коде запрещены `unwrap`/`expect`/`unsafe`; ошибки через `Result` + `?`.
  Ошибка метода компоненты (`AddinResult`) превращается в исключение 1С.
- Перед завершением задач прогонять строго по порядку:
  `cargo fmt` → `cargo clippy --all-targets -- -D warnings` → `cargo test`.

## Ограничения

- Зависимости строго три и без изменений: `native_api_1c = "0.10.7"`,
  `utf16_lit = "2.0.2"`, `translit = "0.8.0"`. Новые зависимости — только после
  согласования.
- Код размещён в корне `translit_dll`, edition 2024 — согласованное исключение
  из `.clinerules/20-rust.md` (которая предписывает edition 2021).
- Сборка только под Windows (MSVC); linux-задачи в `Makefile.toml` (gnu) не
  используются.
- Тестирование выполняется только в Rust. Интеграционное тестирование в самой
  1С — вне объёма проекта.
- Эталонный проект `byte_reader_addin` — только для чтения, правки запрещены.
