# Правила для Rust

- Каталог проекта: rust/.
- Edition 2021 (или актуальная в Cargo.toml).
- Перед завершением задачи запускай по порядку:
  1. cargo fmt
  2. cargo clippy --all-targets -- -D warnings
  3. cargo test
- Исправляй все предупреждения clippy в изменённом коде.
- Избегай unwrap() и expect() в рабочем коде, используй Result и ? с осмысленными ошибками.
- Новые зависимости добавляй только после согласования, указывай причину и версию.
- Не используй unsafe без явной необходимости и обоснования в комментарии.
