# Использование MCP

- Перед использованием незнакомого метода платформы запроси его описание через MCP со справкой.
- Если MCP недоступен, ищи в docs/1c-api, затем в существующем коде проекта.
- проверяй сигнатуры
  и совместимость с 8.3.27 и БСП 3.1.
- Не отправляй через MCP в сторонние сервисы код с секретами, персональными данными
  и коммерческой тайной.
- MCP с доступом к живой базе не подключаем. Работаем только с файлами и справкой.
