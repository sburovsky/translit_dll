# Запросы и производительность

- Запросы не должны выполняться в циклах. Собирай данные пакетным запросом
  или с временной таблицей.
- Выбирай только нужные поля, не используй ВЫБРАТЬ * в смысле лишних полей.
- Используй параметры запроса, не склеивай значения строкой.
- Условия по индексируемым полям, соединения по индексированным ключам.
- Избегай обращений через точку к полям составного типа и к полям нескольких уровней
  в произвольных запросах без необходимости.
- Для больших выборок используй пакетные запросы и временные таблицы,
  а выгрузку в таблицу значений делай только когда она нужна.
- Блокировки данных (транзакции, управляемые блокировки) используй осознанно,
  объясни, зачем они нужны.
- Не используй Объект.Прочитать() и Получить() в цикле для массовых операций.
- Для запросов, влияющих на нагрузку, добавь пояснение в комментарий.
- Не выполняй запросы в клиентском коде. Запросы только на сервере.
- описание языка запросов смотри в MCP по синтакс-помощнику (если он настроен и доступен) и по ссылке https://infostart.ru/1c/articles/204054/
