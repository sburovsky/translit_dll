
Дано: есть проект на языке Rust (назовем его byte_reader), который создает native библиотеку для 1С, которая читает файл в двоичные данные.
Описание работы и создания библиотеки здесь: https://infostart.ru/1c/articles/1920565/ 
Сам проект byte_reader здесь: D:\work\git\repository\Rust\byte_reader_addin
Внимание! Проект byte_reader используется только как пример разработки, вносить любые изменения в файлы проекта запрещено!
Требуется:
1. Подготовить среду разработки Rust согласно описанию https://infostart.ru/1c/articles/1920565/. 
Перед установкой проверить существующую установку. Если требуемое ПО уже установлено, не переустанавливать заново
2. Новый проект не создавать, использовать существующий текущий проект по пути D:\work\git\repository\Rust\translit_dll.
3. Взяв в качестве примера byte_reader_addin реализовать новую версию библиотеки: вместо  чтения файла новая библиотека должна производить транслитерацию.
Для транслитерации использовать крэйт translit
Репозиторий translit: https://github.com/ava57r/translit-rs
Документация translit: https://docs.rs/translit/0.8.0/translit/
Итоговая библиотека должна принимать в качестве параметра строку на кириллице, подлежащую транслитерации, и возвращать готовую транслитерированную строку на латинице.
Итоговую библиотеку для 1С поместить в каталог текущего проекта out
4. После завершения разработки протестировать код в Rust, как указано в описании https://infostart.ru/1c/articles/1920565/, в 1С полученную библиотеку не тестировать
