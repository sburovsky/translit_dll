## Шаг 3. Реализация (src\lib.rs, по образцу byte_reader_addin\src\lib.rs)
- Структура компоненты: TranslitAddin, через #[derive(AddIn)], с полем #[add_in_con].
- Метод:
    #[add_in_func(name = "Transliterate", name_ru = "Транслитерировать")]
    #[arg(Str)]   // Исходная строка (кириллица)
    #[arg(Str)]   // Код системы транслитерации; пустая строка — система по умолчанию
    #[returns(Str, result)]
- Если native_api_1c 0.10.7 поддерживает значение по умолчанию для параметра,
  объявить второй параметр необязательным со значением "". Если не поддерживает
  (сверить с исходниками крейта), оставить его обязательным, а пустую строку
  считать системой по умолчанию.
- Коды систем (сравнение без учёта регистра, пробелы по краям отбрасываются):

  | Код (основной) | Синонимы                  | Система                               | Функция translit          |
  |----------------|---------------------------|---------------------------------------|---------------------------|
  | GOST           | "" (пусто), ГОСТ, GOST779B | ГОСТ 7.79-2000, система Б (по умолч.) | gost779b_ru()             |
  | PASSPORT       | ICAO, ЗАГРАНПАСПОРТ        | Загранпаспорт РФ 2013 (ICAO Doc 9303) | iternational_passport_2013_ru() |
  | DRIVER         | ВУ, ВОДИТЕЛЬСКОЕ           | Водительское удостоверение (Приказ МВД №995) | order_n_995_ru()   |

- Неизвестный код → ошибка (Err) с текстом, в котором перечислены допустимые коды.
  В 1С она станет исключением.
- Транслитерация: Transliterator::new(<таблица>) и трейт ToLatin::to_latin.
  Символы, которых нет в таблице (латиница, цифры, знаки), передаются без изменений.
- Разбор кода системы вынести в отдельную функцию, а саму транслитерацию — в отдельную
  публичную функцию, независимую от FFI, чтобы её можно было тестировать.
- В рабочем коде без unwrap/expect/unsafe. Документирующие комментарии к публичным элементам.

## Шаг 4. Тестирование (только Rust, в 1С не тестировать)
Юнит-тесты в src\lib.rs (#[cfg(test)]):
- каждая система на фразе «Съешь же ещё этих мягких французских булок»;
  ожидаемые значения сверять с таблицами в исходниках translit 0.8.0, не придумывать;
- пустой код и код "ГОСТ" дают тот же результат, что и "GOST";
- коды без учёта регистра и пробелов ("passport", " Driver ");
- неизвестный код → Err;
- пустая исходная строка → пустая строка;
- смешанный текст (кириллица + латиница + цифры) → латиница и цифры не меняются;
- регистр сохраняется (ПРИВЕТ / привет), отдельно проверить ё/Ё, ъ, ь.
Затем выполнить строго по порядку, всё должно пройти без ошибок и предупреждений:
  cargo fmt; cargo clippy --all-targets -- -D warnings; cargo test; cargo make pack
