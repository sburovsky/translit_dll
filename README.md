# translit_addin

Внешняя компонента 1С:Предприятие (Native API) на Rust для транслитерации русского текста
(кириллица → латиница). Поддерживает три системы транслитерации.

## Возможности
- Транслитерация строки по ГОСТ 7.79-2000 (система Б), по правилам загранпаспорта РФ (ICAO, 2013)
  или водительского удостоверения (Приказ МВД № 995).
- Система задаётся вторым параметром. Параметр необязательный, по умолчанию используется ГОСТ 7.79-2000 Б.
- Латиница, цифры и знаки препинания передаются без изменений, регистр сохраняется.
- Сборка для Windows x86 и x64 в один ZIP-архив, готовый для загрузки в макет 1С.

Установка недостающих инструментов:
```powershell
rustup target add x86_64-pc-windows-msvc i686-pc-windows-msvc
cargo install cargo-make
```

## Сборка
```powershell
cargo make pack
```
Команда очищает проект, собирает release-версии для x86 и x64 и складывает результат в каталог `out`:

| Файл | Назначение |
|---|---|
| `out/translit_x32.dll` | компонента для 32-разрядной платформы |
| `out/translit_x64.dll` | компонента для 64-разрядной платформы |
| `out/Manifest.xml` | манифест компоненты |
| `out/translit.zip` | архив для загрузки в макет 1С |

## Тестирование
```powershell
cargo fmt
cargo clippy --all-targets -- -D warnings
cargo test
```
Юнит-тесты находятся в `src/lib.rs`. Они проверяют каждую систему транслитерации, синонимы кодов,
нечувствительность к регистру, пустые строки, смешанный текст и обработку неизвестного кода.

## Подключение в 1С
1. В Конфигураторе создайте общий макет типа **«Двоичные данные»** (например, `translit`)
   и загрузите в него `out/translit.zip`.
2. Установите и подключите компоненту, затем создайте объект:

```bsl
&НаКлиенте
Асинх Процедура Транслит()

	АдресКомпоненты = "ОбщийМакет.translit";
	ИмяКомпоненты   = "Translit";

	Подключено = Ждать ПодключитьВнешнююКомпонентуАсинх(АдресКомпоненты, ИмяКомпоненты, ТипВнешнейКомпоненты.Native);
	Если Не Подключено Тогда
		Ждать УстановитьВнешнююКомпонентуАсинх(АдресКомпоненты);
		Подключено = Ждать ПодключитьВнешнююКомпонентуАсинх(АдресКомпоненты, ИмяКомпоненты, ТипВнешнейКомпоненты.Native);
	КонецЕсли;

	Если Не Подключено Тогда
		ВызватьИсключение "Не удалось подключить внешнюю компоненту " + ИмяКомпоненты;
	КонецЕсли;

	ОбъектВК  = Новый("AddIn." + ИмяКомпоненты + ".TranslitAddin");
	Результат = Ждать ОбъектВК.ТранслитерироватьАсинх(Объект.ИсходнаяСтрока, Объект.СистемаТранслитерации);

	Сообщить(Результат.Значение);

КонецПроцедуры
```

> Имя типа объекта: `AddIn.<имя, указанное при подключении>.TranslitAddin`.
> Для тонкого клиента и веб-клиента компоненту нужно предварительно установить (`УстановитьВнешнююКомпонентуАсинх`).

## API компоненты

### Транслитерировать / Transliterate
```
Транслитерировать(ИсходнаяСтрока, СистемаТранслитерации = "") → Строка
```
| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `ИсходнаяСтрока` | Строка | да | текст на кириллице |
| `СистемаТранслитерации` | Строка | нет | код системы (см. ниже). Пустое значение означает ГОСТ 7.79-2000 Б |

**Возвращает:** строку на латинице.
**Исключение:** вызывается при неизвестном коде системы. В тексте ошибки перечислены допустимые значения.

Метод можно вызывать синхронно (`ОбъектВК.Транслитерировать(...)`) или асинхронно
(`Ждать ОбъектВК.ТранслитерироватьАсинх(...)`, результат в свойстве `.Значение`).

## Системы транслитерации
Регистр кода и пробелы по краям не учитываются.

| Код | Синонимы | Система | Пример: «Съешь ещё» |
|---|---|---|---|
| `GOST` (по умолчанию) | пустая строка, `ГОСТ`, `GOST779B` | ГОСТ 7.79-2000, система Б | ``S``esh` eshhyo`` |
| `PASSPORT` | `ICAO`, `ЗАГРАНПАСПОРТ` | загранпаспорт РФ, 2013 (ICAO Doc 9303) | `Sieesh eshche` |
| `DRIVER` | `ВУ`, `ВОДИТЕЛЬСКОЕ` | водительское удостоверение (Приказ МВД № 995) | `Sieesh eshche` |

Особенности таблицы ГОСТ в крейте `translit`: `ь` → `` ` ``, `ъ` → ``` `` ```, `ы` → ``y` ``,
`э` → ``e` ``, `х` → `x`, `ц` → `c`, `ё` → `yo`.

## Примеры
```bsl
ОбъектВК.Транслитерировать("Привет");                  // "Privet" (ГОСТ)
ОбъектВК.Транслитерировать("Ёж", "PASSPORT");          // "Ezh"
ОбъектВК.Транслитерировать("Ёж", "гост");              // "Yozh"
ОбъектВК.Транслитерировать("Дом 15 Abc", "ICAO");      // "Dom 15 Abc"
ОбъектВК.Транслитерировать("соль", "ВУ");              // "sol"
ОбъектВК.Транслитерировать("тест", "XXX");             // исключение: неизвестная система
```

## Решение проблем
| Симптом | Причина и решение |
|---|---|
| `ПодключитьВнешнююКомпонентуАсинх` возвращает `Ложь` | компонента не установлена: вызовите `УстановитьВнешнююКомпонентуАсинх` |
| «Тип не определен (AddIn.…)» | неверное имя типа: используйте `AddIn.<Имя>.TranslitAddin` |
| После пересборки работает старая версия | перезапустите клиент 1С: загруженная компонента не выгружается |
| Компонента не загружается на другой машине | установите Visual C++ Redistributable 2015–2022 нужной разрядности |
| Ошибка при загрузке макета | макет должен иметь тип «Двоичные данные» и содержать `translit.zip`, а не DLL |
